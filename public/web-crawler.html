What is web crawling?

Web crawling means fetching a page, discovering its links and visiting other pages. Search engines use crawlers to discover content. An SEO crawler uses that process to find problems such as broken links, missing page descriptions and inconsistent headings.

Scout offers a single-page audit and a whole-site crawl capped at 50 pages. It checks robots.txt first, stays on the same hostname and fetches pages one at a time with a short pause.

Web crawling vs. web scraping

Web crawling discovers pages

A crawler follows links to discover and inspect URLs. Scout uses this to audit a website and group repeated issues across its pages.

Web scraping extracts selected data

A scraper usually collects chosen fields, such as product prices or article text, into a dataset. Scout extracts page metadata, headings and link information for audits. It is not a general-purpose data extraction service or a bulk export tool.

Know the limits before you start

Scout reads server-returned HTML. It does not execute JavaScript, sign in to private pages or bypass robots.txt. Content rendered only in a browser can be missed. Its speed checks are not a Core Web Vitals or Lighthouse measurement, and an audit score is not a promise of search rankings.

Whole-site crawls are limited to two per ten minutes per visitor. Reports are public, so do not audit URLs you need to keep private.
