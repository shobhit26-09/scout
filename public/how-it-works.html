How Scout works

Plain rules, applied the same way every time. Here is what Scout looks at, how it turns that into a score, and what it will not do.

From URL to report

  1. Check the rules.Scout fetches robots.txt first. If the page is disallowed for crawlers, it stops and tells you. Private and local addresses are refused.
  2. Fetch the page.One request, identified as ScoutBot, the way a search engine would see it. It records response time, size and headers.
  3. Run the checks.The HTML is parsed and every check runs against it. Links are probed, and the sitemap is looked up. For whole-site crawls, Scout follows internal links up to 50 pages with a short pause between pages.
  4. Look up trust signals.The domain is checked against Google Safe Browsing and public registration data (RDAP), alongside URL and page patterns.
  5. Save and score.Findings are scored, saved, and given a link of their own. A screenshot is requested from a free screenshot service.

How the score works

Every score starts at 100 and loses points for each problem. No weighting tricks and no machine learning, so the same page gets the same score.

Finding typePoints lost
critical12
warning5
info1.5
pass0

Overall score uses all findings together. Category scores use only that category's findings, so a weak Security score does not hide a strong SEO one.

Colors: 85 and up is good, 60 to 84 needs work, under 60 needs attention.

Whole-site crawls score each page the same way and group identical issues, so you see "missing meta description on 9 pages" instead of nine rows.

What each category looks at

SEO

  • Title and meta description length
  • One clear h1
  • Canonical URL
  • noindex directives
  • Structured data (JSON-LD)

Performance

  • Response time
  • HTML size and compression
  • Render-blocking scripts
  • Lazy-loaded images
  • Redirects before the page
  • Image dimensions

Security

  • HTTPS and HSTS
  • Content-Security-Policy
  • Clickjacking, nosniff, referrer and permissions headers
  • Mixed content
  • Cookie flags and server details exposed

Accessibility

  • Image alt text
  • Heading order
  • Page language
  • Descriptive link text

Crawlability

  • robots.txt present and sane
  • Whether all crawlers are blocked
  • Sitemap present

Links

  • Broken links, checked with a request each
  • Count of internal and external links

Mobile

  • Viewport meta tag, so pages scale properly on phones

Social

  • Open Graph tags
  • Twitter/X card
  • Favicon

Scout reads the HTML a server returns. It does not run JavaScript, so content added only in the browser is not seen, and it is not a replacement for real-user speed tools.

The Trust verdict

A fast, evidence-based read on whether a site looks like a scam. It is a risk signal, not a guarantee in either direction.

SafeNo meaningful signals found.
Suspicious3 or more warning points. Check before you pay or sign in.
High riskA Google Safe Browsing hit, or 6 or more points.

Blacklist

  • Google Safe Browsing lookup for malware, social engineering, unwanted software and harmful apps
  • Any hit is High risk by itself
  • If the lookup is unavailable, the verdict says so and uses the other signals

Domain age

  • Registration date from public RDAP records
  • Under 6 months adds warning points
  • Under 30 days is a strong signal

URL patterns

  • Raw IP addresses and punycode lookalikes
  • Link shorteners and risky domain endings
  • Brand names inside unrelated domains

Page patterns

  • Password form on a page that names a known brand
  • Pressure language such as "account suspended"
  • Missing contact details or only a webmail address
  • Trust badges with no source

Every flag in a report shows the exact evidence behind it. For whole-site crawls the verdict is computed once, on the homepage.

What gets stored

Each report is saved so it can live at its own link, and recent audits are listed on the homepage. That is the audited page's results, not anything about you. Scout has no accounts and no trackers. Do not audit pages you want to keep private. The code is open: github.com/shobhit26-09/scout.
